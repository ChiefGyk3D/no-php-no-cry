The code of this site sets no cookies and embeds nothing from other sites. Following a link takes you to another site, which has its own policies. The share links under a post are plain links to the sites they name; the site does not see what you do there. The Mastodon and Lemmy share buttons open a small box on the page that asks for your instance name. The name is checked in your browser and used only to open that instance in a new tab. If you tick Remember, the optional instance name is kept in your own browser, on this site only, so you are not asked again; otherwise it is not kept. Nothing is sent to this site or anyone else while you type or before you press Share; when you press Share, your browser opens the instance you named, which receives that request like any link. Unticking Remember removes the stored name. The Copy link button copies the post address to your clipboard and sends nothing.

The site is hosted on Cloudflare Pages, and Cloudflare Web Analytics is turned on for it. The content security policy on this site allows that analytics script and nothing else from outside. Cloudflare describes Web Analytics as collecting page-load timing and the country, browser, referring site, and page path of each visit, without cookies and without personal data. This page does not describe what Cloudflare logs on its own, such as request or security records.
